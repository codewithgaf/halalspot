# HalalSpot Data Sources

## Philippine Localities

HalalSpot uses a local Philippine Standard Geographic Code
(PSGC) directory to support city and municipality search.

- Geographic data source: Philippine Statistics Authority (PSA)
- Dataset: PSGC, Second Quarter 2026
- Derived from: https://github.com/Tenasia/ph-psgc
- Pinned source revision: ed0c3da59d2a7feea497adc1c867b72007b30118
- Local dataset: resources/data/philippine-cities.json
- Records: 1,642 cities and municipalities

The upstream project's software and data arrangement use
the MIT License. See docs/licenses/ph-psgc-MIT.txt.

PSGC codes and geographic names are credited to the
Philippine Statistics Authority.

Official PSGC:
https://psa.gov.ph/classification/psgc
