# HalalSpot – Find Halal Places Near You

**Discover halal food establishments near you through an interactive, location-based platform.**

HalalSpot is a web application designed to help users discover and explore halal food establishments in their area. By combining an interactive map with restaurant listings, the platform aims to make finding halal dining options more convenient and accessible.

> 🚧 **Project Status: In Development**
>
> HalalSpot is an ongoing personal development project. Features and functionality are continuously being developed and improved.

---

## Overview

Finding halal food establishments in unfamiliar locations can be challenging. HalalSpot aims to address this by providing a centralized platform where users can explore nearby halal food establishments through an interactive map and organized listings.

The project focuses on location-based discovery, usability, and accessible information to help users make more informed dining decisions.

## Current Features

The following features are represented in the current development interface:

- **Interactive Map** – Explore locations through an interactive map interface.
- **Restaurant Listings** – View available halal food establishment listings.
- **Location Information** – Display establishment names and their associated locations.
- **Verification Status** – Identify whether a listing has been marked as verified or is still unverified.
- **Dashboard Interface** – Navigate the application through an organized dashboard layout.

## Technology Stack

HalalSpot is being developed using the VILT Stack:

| Technology   | Purpose                                              |
| ------------ | ---------------------------------------------------- |
| Vue.js       | Frontend development and interactive user interfaces |
| Inertia.js   | Connects the frontend with the Laravel application   |
| Laravel      | Backend application framework                        |
| Tailwind CSS | Responsive styling and UI development                |

Additional tools and integrations may be included as development progresses.
